# FAQ Accordion

A simple FAQ accordion component with responsive design, built as a solution to a Frontend Mentor challenge.

## Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox)
- JavaScript (Vanilla)
- Work Sans font (Variable font)

## Project Structure

```
faq-accordion/
│
├── assets/              # All static assets
│   ├── fonts/           # Work Sans font files
│   └── images/          # SVG icons and background patterns
│
├── styles/              # CSS files
│   ├── font.css         # Font declarations
│   └── style.css        # Main styles
│
├── index.html           # Main HTML document
├── index.js             # JavaScript for accordion functionality
└── README.md            # This file
```

## How to Use Locally

1. Clone the repository
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory
   ```
   cd faq-accordion
   ```

3. Open `index.html` in your browser
   ```
   # Using Firefox
   firefox index.html
   
   # Using Chrome
   google-chrome index.html
   
   # Or simply double-click the file in your file explorer
   ```

No build steps or dependencies required. The project uses only vanilla HTML, CSS, and JavaScript.
